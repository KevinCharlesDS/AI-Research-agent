# AI Research Agent 

A command-line AI agent that helps you research any topic by querying web search and Wikipedia, summarizing results using Llama 3.2 (via Ollama), and saving the output to a text file.

##  Features

- Queries DuckDuckGo Search and Wikipedia
- Summarizes results using Llama 3.2
- Outputs structured research summaries
- Saves the final output to a timestamped `.txt` file

##  How to Run

1. Install dependencies:

pip install -r requirements.txt

2. Start the agent:

python main.py
